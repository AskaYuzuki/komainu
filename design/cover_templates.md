# 表紙の型の控え(11/13 あすかさん「似たようなデザインの使い回しになっていないか。テンプレートを読み直して新しいものを学習して」)
参考：Adobe Express の無料テンプレート PDF(/mnt/user-data/uploads/無料テンプレート_Adobe-Express-11-08-2026_09_44_AM.pdf・5頁・約915点)。レイアウトの考え方だけを借りる。

## 使った型(同じものを2度使わない)
photo / frame / flambay / travel / steer / pale / oshi / sweets / nordic / curve / band / expose / minimalw / grayside / letter / couture / esteem /
coverlines / circlewin / vertname / framewin / collage / duotone / stacked / repeat / sun(南宮) / arch(伊吹山)
使わない：contents(大きな数字)・splitband(上下分けで下半身が隠れる)・sideband(縦帯)・pair2(アーチ2つ・ポラロイドは11/13 不採用案)

## 今回足した型
- tate(伊富岐 明治)：白地・上に細い罫と誌名・左に大きな写真・右に明朝の縦書きで神社名と一行(キャンバス／冬の予定 などの和文誌ふう)
- untamed(伊富岐 大正)：上下に極太の大文字の帯(KOMAINU／年号)、間に写真を横いっぱい(UNTAMED / OUT NOW ふう)

## まだ使っていない型の候補(PDF より)
- big-word-behind：大きな単語(RED のように)を像の後ろに置き、切り抜いた像を手前に。単語は像で一部隠れても読める短いもの
- word-split：BE BOLD BE YOU のように大きな単語を2段に割り、像が段の間に入り込む
- vertical-words-both：ELEGANT｜写真｜FASHION のように左右に縦の単語(※縦帯は不採用なので文字だけにする)
- serif-overlap：Q&A With Clara Devine のように細い大きなセリフ体の名前が写真に重なる(白黒写真)
- giant-letters-column：THE LOOK のように L/O/O/K を縦に積む
- circle-flowers：円の中の写真に植物(紅葉・苔)が重なる
- ticket：Fashion Week のように日付を大きく入れたチケット・入場券ふう
- blur-minimal：ぼかした地に小さな誌名だけ(Modern Magazine)
- satin-dark：黒地に白い極太の詰め文字(MIDNIGHT LUXE)と小さな写真の窓
- toc-list：1〜5の番号付きの見どころの列挙(大きな数字ではなく小さい番号)
- magazine-jp：D-ism のように白黒写真＋大きなセリフ体の誌名＋和文の小見出しを数行

## 11/13 あすかさんに教わった参考サイト：434 magazine world(洋雑誌の定期購読ショップ) https://www.434-magazineworld.com/SHOP/357704/list.html
洋雑誌の実物の表紙(TIME・VOGUE・Forbes・AD・ELLE DECOR・VERANDA・Victoria・Smithsonian・PleinAir・Discover・bake など)から学んだ型：
- time-frame：太い色の額縁で写真を囲み、誌名を写真の上に大きく(TIME の赤枠)→ 11/13 伊富岐神社の2対で採用(明治＝苔色、大正＝弁柄色。同じ型で色だけ変えた「対になる表紙」)
- vogue-behind：誌名を被写体の頭の後ろに通す(※像の顔を隠さない範囲で)
- newsstand-lines：写真全面＋上に大きなセリフ体の誌名＋左に見出し(cover lines)を数行(Forbes・House Beautiful)
- painting-frame：写真を絵画のように白い余白で囲み、誌名と細い見出しは上だけ(PleinAir・American Art Collector)
- burnt-hole：紙に穴が開いたように写真をのぞかせる(Smithsonian)
- script-mast：筆記体の誌名＋花や小物を前景に(Victoria)
## 同じ神社の複数の対は、型をそろえて色や写真だけ変えると「対になる表紙」としてまとまる(11/13 あすかさん：明治版と大正版のデザインが違いすぎる)
## 像は頭から足先まで入れる。台座は切ってよい(11/13 あすかさん)

## 11/14 434 magazine world の2・3ページ目(list2.html・list3.html、全93誌)から学んだ型
URL：1ページ目 https://www.434-magazineworld.com/SHOP/357704/list.html ／2ページ目 …/list2.html ／3ページ目 …/list3.html
- natgeo-frame：黄色の細い長方形の枠を写真の上に重ね、誌名は枠の上(National Geographic)。枠の色は1色に決める
- bw-script：白黒写真に、赤い筆記体の誌名と赤い見出し(Esquire)
- mast-behind-head：誌名の一部が頭の後ろに隠れる(GQ・Vanity Fair・Town&Country)※狛犬の顔は隠さない
- huge-number：巨大な数字(50・100・500)を写真に重ねる(Fast Company・Inc.・Traveler)※「大きな数字を並べる」は不採用なので1つの数字だけ・奉納年などに限る
- flat-object：無地の色面に物を1つだけ置く(Foreign Affairs の爆弾・The Atlantic の椅子・HBR の風船)→ 切り抜いた狛犬を1体だけ無地に
- red-box-logo：左上に赤い四角の誌名と1行の見出しだけ(The Economist)
- illustration-full：絵だけで文字は誌名と日付(The New Yorker)→ 写真を絵画調に
- name-bottom：白黒の顔の大写し、下に名前を大きく(OUT・Vanity Fair)
- moody-dark：暗い写真に細い誌名を薄く(roast・Barista)
- white-minimal：白地に小さな写真、誌名と短い見出しだけ(dwell・The Atlantic)
- craft-lines：見出しを色を変えて何行も(手芸誌・料理誌)※狛犬には向かない
