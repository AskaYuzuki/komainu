# 表紙テンプレートの一覧(番号つき・使ったら印をつける)

11/24 あすかさん「テンプレートを1000種類以上渡しているにも関わらず、プロジェクト内で保持しているテンプレートが9種類ほどしかなくてそれを使いまわしている」→ 最高司令官が、渡されたテンプレートを1つずつ番号をつけて並べた。

## 使い方(毎回かならず)
1. 下の一覧で「未使用」のうち、いちばん番号の小さいものから3つを選ぶ(順番に進めるので、同じものに戻らない)。
2. 3つの画像を実際に開いて見る(434 は URL を curl で落として Read で見る。Adobe は Drive の画像を見る)。見ないで作らない。
3. 3つのうち、cover_templates.md の「単調にしないための決まり」(直近5つと5項目のうち3つ以上違う)に合うものを1つ選び、そのテンプレートのレイアウト(誌名の位置・書体・写真の置き方・枠・色)をまねて作る。写真や文字はそのまま使わない。
4. 使ったら、その行の「未使用」を「使用：神社名 対のid(日付)」に書き換える。見たが合わなかった2つは「見送り(日付)」と書く(見送りは後でまた使ってよい)。
5. cover_templates.md の「直近の表紙の記録」にも、テンプレート番号を書く。
