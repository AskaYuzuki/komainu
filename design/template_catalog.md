- A001〜A918：Adobe Express 無料テンプレート(あすかさんの PDF。Drive handover/表紙テンプレート_AdobeExpress_PDF画像/番号つき一覧(A001-A918)/ に24点ずつの一覧画像。ファイル名が番号の範囲)
- C001〜C240：Canva 雑誌の表紙テンプレート(公開ページで見られる240点。Drive handover/表紙テンプレート_Canva_番号つき一覧(C001-C240)/ に24点ずつの一覧画像。1点ずつの画像は下の表の URL を curl で落とせる)
- M001〜M093：434 magazine world(下の表の URL を curl で落とす)

## 使い方(表紙を作るたびに、かならず)
1. A・C・M から1つずつ、「未使用」のいちばん小さい番号を選ぶ(合計3つ)。
2. 3つの画像を実際に開いて見る。A と C は Drive の一覧画像を download_file_content で落として Read で見る(該当番号を見つける)。C と M は URL を curl で落としてもよい。見ないで作らない。
3. 3つのうち、cover_templates.md の「単調にしないための決まり」(直近5つと5項目のうち3つ以上違う)に合うものを1つ選び、レイアウト(誌名の位置・書体・写真の置き方・枠・色)をまねて作る。テンプレートの写真や文字はそのまま使わない。狛犬に向かない要素(セール・価格・大量の文字)は省く。
4. 使ったら、その行を「使用：神社名 対のid(日付)」に書き換える。見たが合わなかった2つは「見送り(日付)」にする(見送りは次の回でまた候補にしてよい。ただし3回見送ったら「不向き」にして飛ばす)。
5. cover_templates.md の「直近の表紙の記録」と、あすかさんへの報告に、使った番号を書く(例：A014・C032・M007 を見て A014 を使用)。
6. その対のフォルダの check.md(リポジトリ research/check_template.md の写し)の「表紙」欄に番号を書く。書いていないと投稿の定例タスクが投稿しない。
