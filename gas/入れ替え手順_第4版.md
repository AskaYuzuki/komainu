# 受け取り口を第3版から第4版に入れ替える（パソコンで5分）

受け取り口のURLと合言葉は変わりません。iPhone のアプリの設定もそのままです。

## 1. 今の合言葉を控える
1. パソコンで https://script.google.com を開き、「狛犬撮影 受け取り口」を開きます
2. 上から16〜18行目あたりの `const AIKOTOBA = '……';` の `'` と `'` の間の合言葉を、メモアプリなどに控えます

## 2. 中身を第4版に入れ替える
1. https://askayuzuki.github.io/komainu/gas/Code.gs.txt を別のタブで開き、全部選んで（Mac は ⌘＋A、Windows は Ctrl＋A）コピーします
2. Apps Script の画面に戻り、真ん中の中身を全部選んで消し、コピーしたものを貼り付けます
3. 上から18行目の `const AIKOTOBA = 'ここに合言葉を書く';` の **ここに合言葉を書く** だけを、1で控えた合言葉に書き換えます（前後の `'` は残す）
4. 上の「保存」（フロッピーの絵）を押します

## 3. 公開し直す（URLを変えずに）
1. 右上の青い「デプロイ」→「**デプロイを管理**」を押します
2. 右上の鉛筆のマークを押します
3. 「バージョン」を「**新バージョン**」にして、「デプロイ」を押します
   - 「新しいデプロイ」は選びません（URLが変わってしまいます）
4. 承認の画面が出たら「権限を確認」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」

## 4. iPhone で確かめる
1. 撮影アプリを閉じて開き直します（変わらなければもう一度）
2. 右上の設定ボタン →「つながるか確かめる」→「つながりました」と出れば完了です

うまくいかないときは、画面のスクリーンショットを送ってください。
