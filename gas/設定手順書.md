# 狛犬撮影アプリ 設定手順書（第4版）

撮影アプリから送った写真を Google ドライブの「狛犬プロジェクト/受信箱」に届けるための準備です。パソコンで、最初に一度だけ行います。所要時間は15分ほどです。

**第1版〜第3版の受け取り口をすでに作ってある場合**は、1〜5はいりません。いちばん下の「前の版から第4版に入れ替える」だけ行ってください。

第4版の受け取り口でできるようになること：

- **写真の取り消し**：撮影アプリで送信済みの写真を「取り消す」と、受信箱のその写真をゴミ箱に入れ、metadata.json の一覧と枚数からも外します
- **対ごとの感想**：撮影アプリで対ごとに書いた感想を、metadata.json の pairs に記録します

これまでの、対ごとの「生き物」（狛犬・狐・蛙など）と「1体だけ」の記録、iPhone から Instagram に投稿するときの画像の受け渡しと「投稿済み」の記録もそのままです。

## 用意するもの

- パソコン（Chrome がおすすめ）
- Google アカウント：**受信箱フォルダに書き込めるアカウント**を使います。いちばん確実なのは、狛犬プロジェクトのフォルダを持っている future.awakening.project@gmail.com です。写真が入っている Google フォトのアカウント（u/3）と同じでなくてかまいません
- この手順書と同じフォルダにある「Code.gs」の中身

## 1. 合言葉を決める

アプリと受け取り口だけが知っている言葉です。知らない人が写真を送り込めないようにするためのものです。

- 半角の英字と数字で12文字以上にします（例の形：komainu7tsukuba2026）
- 他のサービスのパスワードと同じものは使いません
- メモアプリなどに控えておきます。あとで iPhone のアプリにも入れます

## 2. 受け取り口を作る

1. パソコンで https://script.google.com を開きます。右上のアカウントが、上で決めたアカウントになっているか確かめます（違うときは右上の丸いアイコンから切り替えます）
2. 左上の「新しいプロジェクト」を押します
3. 左上の「無題のプロジェクト」を押し、名前を「狛犬撮影 受け取り口」にして「名前を変更」を押します
4. 画面の真ん中に `function myFunction() {` で始まる数行が入っています。これを全部消します（中をクリックして、Windows は Ctrl＋A、Mac は ⌘＋A で全部選んでから Delete）
5. 「Code.gs」の中身を全部コピーして、そこに貼り付けます
6. 貼り付けた中の、上から16行目あたりにある次の行を探します

   `const AIKOTOBA = 'ここに合言葉を書く';`

   `ここに合言葉を書く` の部分だけを、1で決めた合言葉に書き換えます。前後の `'`（半角のかぎ）は消さずに残します
7. 上の「保存」（フロッピーの絵のボタン）を押します

## 3. 書き込めるか確かめる（省いてもかまいません）

1. 上の「実行」ボタンの右にある関数名の欄で `checkSetup` を選び、「実行」を押します
2. 「承認が必要です」と出たら「権限を確認」を押し、使っているアカウントを選びます
3. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「狛犬撮影 受け取り口（安全ではないページ）に移動」→「許可」の順に押します。自分で作ったものなので、この表示が出るのはふつうです
4. 下の「実行ログ」に「書き込みできました」と出れば準備できています

## 4. 公開する

1. 右上の青い「デプロイ」→「新しいデプロイ」を押します
2. 「種類の選択」の歯車のマークを押し、「ウェブアプリ」を選びます
3. 次のように設定します
   - 説明：狛犬撮影 受け取り口
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押します。3で承認していないときは、ここで同じ承認の画面が出るので、3の2〜3と同じように進めます
5. 「ウェブアプリ」の下に `https://script.google.com/macros/s/` で始まるURLが出ます。右の「コピー」を押し、メモアプリなどに貼って iPhone で見られるようにします

※「全員」にしても、合言葉を知らない人は写真を送ることも一覧を見ることもできません。

## 5. 撮影アプリに設定する（iPhone）

1. iPhone の Safari で撮影アプリ（https://askayuzuki.github.io/komainu/satsuei/）を開き、共有ボタン →「ホーム画面に追加」を押します
2. ホーム画面の「狛犬撮影」から開きます。位置情報の確認が出たら「アプリの使用中は許可」を選びます
3. 右上の設定ボタン（横線が2本のボタン）を押します
4. 「受け取り口のURL」に4でコピーしたURLを、「合言葉」に1の合言葉を入れて「保存する」を押します
5. 「つながるか確かめる」を押し、「つながりました」と出れば完了です

※ 設定の「撮ったらすぐ送る」は、初めは「送らない」です。撮った写真は端末にためておき、撮影をおえたあとの画面か「送信」の画面で **「送信する」** を押したときに、写真と対ごとの感想をまとめて送ります。撮るたびに送りたいときは「すぐ送る」を選びます。

## あとで直したいとき

- **合言葉を変えるとき**：script.google.com でこのプロジェクトを開き、16行目あたりの AIKOTOBA の行を書き換えて保存 →「デプロイ」→「デプロイを管理」→ 右上の鉛筆のマーク →「バージョン」を「新バージョン」にして「デプロイ」。URLは変わりません。iPhone のアプリの設定にも新しい合言葉を入れます
- **Code.gs を新しくするとき**：中身を全部入れ替えて保存し、上と同じ「デプロイを管理」→「新バージョン」で公開し直します（「新しいデプロイ」を選ぶとURLが変わってしまうので注意）

## うまくいかないとき

| アプリの表示 | 確かめること |
|---|---|
| 合言葉が受け取り口と違います | アプリの設定の合言葉と、Code.gs の AIKOTOBA の行（16行目あたり）が同じか（大文字・小文字、前後の空白） |
| 対ごとの感想・生き物・「1体だけ」が受信箱の metadata.json の pairs に入らない | 受け取り口が古い版です。下の「前の版から第4版に入れ替える」をしてください（古い版のままでも写真は届きます） |
| 受け取り口が古い版のため、写真の取り消しを受信箱に伝えられません | 下の「前の版から第4版に入れ替える」をしてください。入れ替えたあと「送信する」を押すと、たまっていた取り消しを送ります |
| 写真が送られない（送信待ちのまま） | 設定の「撮ったらすぐ送る」が「送らない」のときは、「送信する」を押したときだけ送ります。「送信」の画面で「送信する」を押してください |
| 受け取り口から思った返事が来ません | URLが `/exec` で終わっているか。デプロイの「アクセスできるユーザー」が「全員」か |
| つながりませんでした | 電波があるか。電波のある所で、もう一度「送信する」を押します |
| server_error と出る | 受け取り口を作ったアカウントが、受信箱フォルダに書き込めるか（3の確認をしてみる） |

## 前の版から第4版に入れ替える

受け取り口のURLと合言葉は変わりません。iPhone のアプリの設定もそのままです。

1. 今の Code.gs の AIKOTOBA の行から、合言葉をメモアプリなどに控えます
2. script.google.com で「狛犬撮影 受け取り口」を開き、中身を全部消して、第4版の「Code.gs」の中身を貼り付けます
3. 上から16行目あたりの `const AIKOTOBA = 'ここに合言葉を書く';` の `ここに合言葉を書く` を、1で控えた合言葉に書き換えて保存します
4. 「デプロイ」→「デプロイを管理」→ 右上の鉛筆のマーク →「バージョン」を「新バージョン」にして「デプロイ」を押します（「新しいデプロイ」は選びません。URLが変わってしまいます）
5. 承認の画面が出たら、3の2〜3と同じように進めます
6. iPhone で撮影アプリを一度閉じて、開き直します（右上の設定の「このアプリについて」に「版 4.0.0」と出ていれば新しい版です。出ていないときは、閉じて開き直すのをもう一度くり返します）
