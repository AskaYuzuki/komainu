## 図録データベース(かならず像と比べる)
11/24 あすかさん「狛犬図鑑、Instagramの記事を作成する際、『狛犬のしっぽ』全国狛犬図鑑の内容だけでなく、かならず、データベースの内容と掲載する像の特徴を比べてから文章を作成すること。データベースの使い方：載っているかを探すのではなく、型・時代背景・ルーツの知識として使うこと。」
- Google Drive の「狛犬図録」フォルダの「狛犬図録データベース_zuroku_db.json」(ID 1P_Yy79JJn0PM4qWwXNDvm2Yv3xdh_DtE。『獅子と狛犬 神獣が来たはるかな道』MIHO MUSEUM編・146件)を download_file_content で読む。
- 手順：(1) 写真を見て像の特徴を書き出す(姿勢・玉/子獅子・尾・たてがみ・口・材質・角)。(2) 同じ特徴をもつ作品をデータベースから2つ以上選び、時代・地域・材質を比べる。(3) 型の流れ・時代背景・ルーツとして、似ている点と違う点を文章に生かす。出典は『獅子と狛犬 神獣が来たはるかな道』MIHO MUSEUM編・青幻舎・2014年 ◯頁。
- 「この像はデータベースに載っていない」で終わらせない。載っていなくても比べる。


## 狛犬千万無量「全国参道狛犬図鑑」の PDF(かならず読む)
11/24 あすかさん「このサイトのPDFの内容を読みに行かせたいです。※今回の宮城の情報だけにかかわらず、毎回文章を書く際に、このサイトから派生しているPDFデータを読ませたいです。」
- サイト：https://komainuzukan.amebaownd.com/ (地域ごとの記事 12本に、県・市ごとの PDF が計191本。Google Drive の公開ファイル)
- 索引：Google Drive handover/ の「狛犬千万無量_PDF索引.tsv」(約3,670対。地域・PDF名・ページ・神社・分類・石工・建立年・鎮座位置・DriveファイルID)
- 手順(キャプション・来歴・図鑑の文章を書くたびに毎回)：
  1. 索引を download_file_content で読み、神社名(旧字・別表記も：鹽竈/塩竈/塩竃 など)と市町村で探す。
  2. 当たった PDF を読む。方法はどちらでもよい：
     - Google Drive コネクタの read_file_content に DriveファイルID を渡す(PDF の文章が読める)
     - シェルで `curl -sL -o x.pdf "https://drive.google.com/uc?export=download&id=<ID>"` → `pdftotext -layout x.pdf x.txt`
  3. 見つからなくても、その県の PDF は目を通す(同じ石工・同じ型の狛犬が近くにあることが多い)。
- 書くときの扱い：分類・石工・建立年・鎮座位置などの事実を確かめるために使う。文章はそのまま写さず、使った事実には「(出典：狛犬千万無量『全国参道狛犬図鑑 ◯◯県』)」と出典をつける。現地で確認したことと食い違うときは現地を優先し、食い違いを記録に書く。
- PDF は作者のものなので、このリポジトリ(公開)に PDF や本文をそのまま置かない。
